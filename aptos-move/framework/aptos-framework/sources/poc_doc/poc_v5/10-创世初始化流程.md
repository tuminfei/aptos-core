# 10 — 创世初始化流程

本文档详细分析 Genesis 模块的完整初始化时序、验证者引导和首个 epoch 触发。

**源文件**：`genesis.move`

## 10.3 Step 2：TopoCoin 初始化

```mermaid
sequenceDiagram
    participant GN as genesis
    participant TC as topo_coin
    participant ST as stake
    participant SR as staking_registry
    participant TF as transaction_fee

    GN->>TC: topo_coin::initialize()
    TC-->>GN: (burn_cap, mint_cap)

    GN->>TC: coin::create_coin_conversion_map()
    GN->>TC: coin::create_pairing<TopoCoin>()

    GN->>ST: store_topo_coin_mint_cap(mint_cap)
    Note over ST: 存储到 TopoCoinCapabilities

    GN->>SR: store_topo_coin_mint_cap(mint_cap)
    Note over SR: 存储到 PendingMintCapability<br/>（等待 initialize 时消费）

    GN->>TF: store_topo_coin_burn_cap(burn_cap)
    GN->>TF: store_topo_coin_mint_cap(mint_cap)
```

**MintCap 的分发路径**：
- `stake` 模块：保留一份（历史兼容）
- `staking_registry`：缓存到 `PendingMintCapability`，在 `initialize()` 时移入 `StakingRegistry`
- `transaction_fee`：用于 mint 退款

## 10.4 Step 3：验证者初始化

### ensure_poc_staking_initialized

```mermaid
flowchart TD
    A[ensure_poc_staking_initialized] --> B{PowerStore operator == 0x0?}
    B -->|是| C["poc_power_store::initialize(operator=@aptos_framework)"]
    B -->|否| D[跳过]

    C --> E[计算 cooldown_secs]
    D --> E
    E --> F["cooldown = max(recurring_lockup_duration, governance_voting_duration)"]
    F --> G["staking_registry::initialize(octas_per_power=100000, max_delegators=1000, cooldown)"]
```

**默认参数**：
- `octas_per_power = 100,000`（0.001 TOPO / 算力单位）
- `max_delegators_per_validator = 1,000`
- `cooldown_secs = max(lockup_duration, voting_duration)`

### create_initialize_validator（每个验证者）

```mermaid
sequenceDiagram
    participant GN as genesis
    participant SR as staking_registry
    participant PS as poc_power_store
    participant ST as stake

    Note over GN: 读取 ValidatorConfigurationWithCommission

    GN->>SR: calculate_genesis_power_from_stake(stake_amount)
    SR-->>GN: genesis_power = stake_amount × multiplier

    GN->>GN: create_account(owner, stake_amount)
    Note over GN: 创建账户并铸造 stake_amount TopoCoin

    GN->>GN: create_account(operator, 0)

    GN->>ST: initialize_stake_owner(owner, 0, operator)
    Note over ST: 创建 StakePool（空壳）<br/>创建 OwnerCapability<br/>创建 ValidatorConfig

    alt 验证者未在 registry 注册
        GN->>SR: register_validator_for_genesis(owner, pool, commission×100)
        Note over SR: commission_percentage → commission_bps<br/>例如 10% → 1000 bps
    end

    GN->>PS: set_genesis_committed_power(owner, genesis_power)
    Note over PS: 直接写入 period 0 的算力

    GN->>SR: deposit(owner, stake_amount)
    Note over SR: TopoCoin 锁入 deposit

    GN->>SR: delegate(owner, pool_address)
    Note over SR: owner 自委托

    alt join_during_genesis == true
        GN->>GN: initialize_validator(pool_address, config)
    end
```

### initialize_validator

```mermaid
sequenceDiagram

    participant ST as stake

    GN->>ST: rotate_consensus_key(operator, pool, pubkey, pop)
    GN->>ST: update_network_and_fullnode_addresses(operator, pool, net, fullnode)
    GN->>ST: join_validator_set_internal(operator, pool)
    Note over ST: 加入 pending_active 队列<br/>设置状态 PENDING_ACTIVE
```

### 首个 epoch 触发

```move
// create_initialize_validators_with_commission 末尾
topo_coin::destroy_mint_cap(aptos_framework);
stake::on_new_epoch();
```

**关键**：
1. 销毁 `aptos_framework` 的 mint 能力（创世后不能再随意铸币）
2. 触发 `on_new_epoch()`，将 pending_active 验证者激活为 ACTIVE

```move
    validator_config: ValidatorConfiguration,

}
```

## 10.6 创世算力计算

```move
public(friend) fun calculate_genesis_power_from_stake(stake_amount: u64): u64 {
    let wide_power = (stake_amount as u128) * (genesis_stake_power_multiplier as u128);
    assert!(wide_power <= MAX_U64, ...);
    wide_power as u64
}
```

默认 `genesis_stake_power_multiplier = 1`，所以：

```
genesis_power = stake_amount × 1 = stake_amount
```

**含义**：创世验证者的初始算力等于其质押金额（octas）。后续算力由链下 Operator 计算并上传。

## 10.8 创世时序图（完整）

```mermaid
sequenceDiagram
    participant RUST as Rust Genesis
    participant GN as genesis.move
    participant AF as Framework Modules
    participant TC as TopoCoin
    participant PS as PowerStore
    participant SR as StakingRegistry
    participant ST as Stake

    RUST->>GN: initialize(gas, chain_id, ...)
    GN->>AF: 初始化所有框架模块
    GN->>ST: stake::initialize()
    GN->>AF: staking_config::initialize(min, max, lockup, ...)

    RUST->>GN: initialize_topo_coin()
    GN->>TC: topo_coin::initialize()
    GN->>ST: store_topo_coin_mint_cap(mint_cap)
    GN->>SR: store_topo_coin_mint_cap(mint_cap)

    RUST->>GN: create_initialize_validators_with_commission(validators)
    GN->>PS: poc_power_store::initialize(@aptos_framework)
    GN->>SR: staking_registry::initialize(100000, 1000, cooldown)

    loop 每个验证者
        GN->>GN: create_account(owner, stake_amount)
        GN->>ST: initialize_stake_owner(owner, 0, operator)
        GN->>SR: register_validator_for_genesis(owner, pool, commission)
        GN->>PS: set_genesis_committed_power(owner, genesis_power)
        GN->>SR: deposit(owner, stake_amount)
        GN->>SR: delegate(owner, pool_address)
        GN->>ST: rotate_consensus_key(operator, pool, pubkey, pop)
        GN->>ST: update_network_and_fullnode_addresses(...)
        GN->>ST: join_validator_set_internal(operator, pool)
    end

    GN->>TC: destroy_mint_cap()
    GN->>ST: on_new_epoch()
    Note over ST: pending_active → ACTIVE<br/>验证者集合正式生效

    RUST->>GN: set_genesis_end()
    GN->>AF: chain_status::set_genesis_end()
```
